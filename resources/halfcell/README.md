# Half-cell electrode data

This directory contains experimentally measured half-cell electrode curves used
as example/reference input for the degradation mode analysis workflow.

The data were recorded at the Chair of Electrical Energy Storage Technology,
Technical University of Munich, and are released under **CC0 1.0 Universal**.
See [`../../DATA_LICENSE.md`](../../DATA_LICENSE.md) for details.

For meaningful analyses, users should replace or configure these curves as
needed so that they match the chemistry of the investigated cell.
